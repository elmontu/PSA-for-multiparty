# Vendored upstream code

This tree contains external cryptographic library sources vendored INTO this
repo (rather than fetched via CMake) to enable an offline, auditable build.
Do NOT modify these files except for surgical include-path rewrites required
to make them compile in this tree; upstream bugfixes should come via a
resync commit, not an in-place edit.

## What's vendored, what's NOT

**Vendored (46 files, ~11500 LOC):**

- `volepsi/`:
  - `RsPsi.{h,cpp}` — 2PC PSI (Rindal-Schoppmann EUROCRYPT'21 + follow-ons)
  - `RsOprf.{h,cpp}` — 2PC OPRF underlying RsPsi
  - `Paxos.h`, `PaxosImpl.h`, `PxUtil.h` — OKVS (Garimella et al. CRYPTO'21)
  - `SimpleIndex.{h,cpp}` — cuckoo indexing
  - `GMW/Circuit.{h,cpp}`, `GMW/Gmw.{h,cpp}`, `GMW/SilentTripleGen.{h,cpp}`
    — Garbled MPC-With framework (needed by MPSO)
- `mpso/`:
  - `mpso/MPSI.{h,cpp}`, `MPSIC.{h,cpp}`, `MPSICS.{h,cpp}`, `MPSU.{h,cpp}`
  - `mpso/PMT.{h,cpp}`, `ROT.{h,cpp}`
  - `common/Defines.h`, `permute.{h,cpp}`
  - `offlineGen/{Beaver,Bool}TriplesGen.{h,cpp}`, `PreGen.{h,cpp}`,
    `RotGen.{h,cpp}`, `VoleGen.{h,cpp}`
  - `shuffle/MShuffle.{h,cpp}`, `ShareCorrelationGen.{h,cpp}`

**NOT vendored (skipped intentionally):**

- Upstream `volePSI/`'s own `CMakeLists.txt`, `fileBased.{h,cpp}`, `Defines.h`
  — we use our own Defines.h and build system, and don't need the upstream
  CLI frontend.
- Upstream `volePSI/RsCpsi*` (Circuit-PSI) and `RsOpprf*` (OPPRF) — MPSO does
  not need them for its MPSI variants.
- MPSO's `test/`, `shell_for_test/`, and `CMakeLists.txt` — we integrate MPSO
  as a library, not as a standalone test binary.
- `volePSI/config.h` — this is generated by upstream CMake from `config.h.in`.
  A hand-rolled version for our feature set is at `volepsi/config.h`
  (see next section).

## Integration status — NOT YET COMPILING

This drop is **files only**. CMake and include-path integration is a
separate follow-on task (see below). Do NOT expect the build to compile with
just this vendor drop landed.

### Known integration blockers to solve in a follow-on session

1. **Namespace collision on `volePSI`.** Both upstream and this repo occupy
   `namespace volePSI`. Local Simple-Hash classes were renamed to
   `RsSimpleHashPsi3rdP*` in Stage B phase 1 to free the `RsPsi*` names.
   The upstream `details::RsPsiBase` is now free of collision — verify.

2. **Include-path rewriting.** Upstream files use `#include "volePSI/foo.h"`,
   which would resolve to this repo's own `volePSI/foo.h`, not the vendored
   `volePSI/upstream/volepsi/foo.h`. Options:
   - (a) sed all upstream `#include "volePSI/X"` → `#include "upstream/volepsi/X"`
     and add `${CMAKE_SOURCE_DIR}/volePSI` to the include path for the
     vendored files' compilation unit only.
   - (b) create a compile-time symlink so `volePSI/` on the include path
     resolves to the vendored subdir when compiling upstream files. Fragile.
   Recommend (a).

3. **Missing `volePSI/config.h`.** Upstream generates this from `config.h.in`
   with three macros: `VOLE_PSI_ENABLE_GMW`, `VOLE_PSI_ENABLE_CPSI`,
   `VOLE_PSI_ENABLE_OPPRF`. Since we vendored GMW but not CPSI/OPPRF, we
   want:
   ```c
   #define VOLE_PSI_ENABLE_GMW  1
   /* #undef VOLE_PSI_ENABLE_CPSI */
   /* #undef VOLE_PSI_ENABLE_OPPRF */
   ```

4. **GMW's old-cryptoTools networking dep.** Upstream `GMW/Gmw.cpp` uses
   `cryptoTools/Network/IOService.h` / `Session.h` — the pre-coproto network
   layer. Our libOTe commit
   (`d55867114c78272be7142bd67ebdcb346fec8621`, fetched via
   `thirdparty/getLibOTe.cmake`) may or may not still ship these headers.
   Verify at build time; if missing, the fix is to port GMW's socket calls
   to coproto (~medium refactor).

5. **New deps.** MPSO also uses OpenMP (`#pragma omp parallel`) and OpenSSL.
   Our build uses libsodium, not OpenSSL. Options: (a) build MPSO with
   `-DVOLE_PSI_ENABLE_OPENSSL=OFF` and see how much breaks; (b) add
   OpenSSL as a first-class dep.

6. **Boost.Math**. Upstream `RsPsi.cpp` uses
   `boost/math/special_functions/binomial.hpp` and
   `boost/multiprecision/cpp_bin_float.hpp`. We already have Boost enabled
   (`VOLE_PSI_ENABLE_BOOST=ON`), so this should just work at link time.

## Update discipline

When resyncing from upstream:
- `cd /tmp && git clone --depth 1 <URL>`
- `diff -r` against the vendored copy; propagate non-conflicting upstream
  changes; note any local include-path or config edits to preserve.
- Update the commit SHAs and date in the provenance table above.
